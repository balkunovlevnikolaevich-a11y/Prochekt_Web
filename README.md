# Prochekt_Web
Этап 1. Создание команд. Описание проекта (срок выполнения 20 апреля 2026 г)
Команда - Ya odin - участник Балкунов Лев Николаевич

Web сайт с возможностью ставить задачи и выполнять их.

Этап 2. Задание (ТЗ) – техническое задание (срок выполнения 23 апреля 2026 г)
Функциональные требования Пользователь может зарегистрироваться, создать задачу, отметить её как выполненную, удалить задачу
Нефункциональные требования( возможность взаимодействования с ии и приятный интерфейс)
Сценарии использования:
  1. Регистрация
  2. Выбор роли (ставит задачу или выполняет)
  3. выбор категории (возможно)
  4. Форма составления задачи
  5. Описывает задачу и выставляет за нее награду
Стек технологий (Python + Flask, HTML/CSS, SQLite).
На главном меню регистрация и выбор задачи
Экран создания задачи - устанавливает параметры задачи
Экран приема задачи - возможность ознакомиться с задачей.
